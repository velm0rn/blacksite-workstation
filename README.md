# BLACKSITE // Cyber Intelligence Workstation

An offline-first, cinematic cyber-intelligence simulation environment built with React, TypeScript, Three.js, Recharts, and xterm.js. Designed as a full-screen desktop operating environment for visual demonstration and entertainment.

> **Disclaimer:** All network telemetry, IP addresses, feeds, operations, and surveillance visuals are 100% synthetic local simulations. This software performs zero external network scanning, intrusion, or real-world surveillance.

---

## One-Click Setup (Windows)

1. Install **[Node.js LTS](https://nodejs.org/)** if you do not already have it.
2. Click the green **`<> Code`** button at the top of this page and select **`Download ZIP`** (or clone the repo), then extract the folder.
3. Double-click **`install.bat`** — it will automatically install all dependencies, generate a `run.bat` launcher, and boot BLACKSITE in your browser.
4. For future launches, simply double-click **`run.bat`**.

## Core Capabilities

- **Cinematic Boot & Authentication:** Animated kernel startup sequence, CRT scanline toggle, multi-theme accent switcher (`Neon`, `Cyan`, `Amber`), low-performance GPU toggle, and procedural Web Audio UI sound effects.
- **Command Center Dashboard:** Live 3D Three.js global node map with animated traffic pulses, real-time system telemetry graphs, filterable cyber-intelligence event stream, active operations tracker, and threat signature monitor.
- **Multi-Tab Root Terminal (`xterm.js`):** Supports multiple tabs, command history (`Up Arrow`), tab-autocomplete, and 19 interactive simulation commands (`help`, `scan`, `trace`, `analyze`, `decrypt`, `matrix`, `globe`, `sysinfo`, `netstat`, and more).
- **Floating Command Palette (`Ctrl + K`):** Instant keyboard-driven navigation across all modules and display toggles.
